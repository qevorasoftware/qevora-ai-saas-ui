Charts

Line, area, bar and doughnut charts built on Chart.js. Every chart is theme-aware: colours are read from the CSS variables, so switching to dark mode re-draws them automatically.

Design tokens
Charts are loaded from assets/js/chart.umd.js plus assets/js/pages/charts.js — nothing is fetched from a CDN. A page only loads them when its entry in src/pages.mjs includes CHART_SCRIPTS.

Usage notes

  • Wrap every canvas in a .chart-holder with --sm, --md or --lg — that fixed height stops the chart from growing on every redraw.
  • Registry keys: revenue, users, aiUsage, tokens, modelUsage, traffic, sales, conversion, and sparkline-primary|success|warning|danger|info.
  • Data attribute overrides: data-labels, data-values, data-series (with ; between series) and data-no-legend="true".
  • Charts re-render on qevora:themechange through QevoraCharts.rebuild() — call it yourself after replacing chart markup with JavaScript.
  • Add role="img" and an aria-label describing what the chart shows; charts are invisible to screen readers otherwise.
  • Never chart more than about six series or twelve categories in a dashboard widget — switch to a table beyond that.
