<button class="btn btn-primary btn-lg">Large</button>

<button class="btn btn-primary"><i class="bi bi-plus-lg"></i> New project</button>
<button class="btn btn-primary">Continue <i class="bi bi-arrow-right"></i></button>

<button class="btn btn-icon btn-primary" aria-label="Add item">
  <i class="bi bi-plus-lg"></i>
</button>

Buttons with state

Loading, toggled and grouped buttons. Toggle buttons use aria-pressed.

<!-- Loading state -->
<button class="btn btn-primary" disabled>
  <span class="spinner-border spinner-border-sm" aria-hidden="true"></span>
  <span role="status">Saving…</span>
</button>

<!-- Button group -->
<div class="btn-group" role="group" aria-label="View mode">
  <button class="btn btn-white active">Day</button>
  <button class="btn btn-white">Week</button>
  <button class="btn btn-white">Month</button>
</div>

<!-- Toggle button -->
<button class="btn btn-soft-primary" aria-pressed="true">
  <i class="bi bi-bookmark-check"></i> Following
</button>

Usage notes

  • Use .btn-primary once per view for the main action; everything else should be soft, ghost or white.
  • Prefer .btn-icon with an aria-label instead of text-only icon links in tables.
  • .btn-soft-* uses the matching soft background token, so it adapts to dark mode automatically.
  • Buttons inherit the 8px radius from --q-radius-sm; change the token to restyle every button at once.
