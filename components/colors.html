Colors

Every colour is a CSS variable, so light and dark mode are driven by the same names. Override them once in assets/css/style.css and the whole template follows.

Design system

Brand and status colours

The seven core tokens used across the template. Each one also has a soft tint for backgrounds and badges.

Primary --q-primary
Accent --q-accent
Success --q-success
Warning --q-warning
Danger --q-danger
Info --q-info
Heading --q-heading-color
Muted text --q-muted-color

Token reference

Change these values to re-brand the whole template

Token Light Dark Used for
--q-primary#4f46e5#7c74ffPrimary actions, links, active navigation
--q-accent#06b6d4#22d3eeSecondary charts, highlights, gradients
--q-success#10b981#34d399Paid, active, completed states
--q-warning#f59e0b#fbbf24Pending, low stock, quota warnings
--q-danger#ef4444#f87171Failed, overdue, destructive actions
--q-info#0ea5e9#38bdf8Informational badges and alerts
--q-body-bg#f6f7fb#0b0f1cApplication background
--q-surface#ffffff#141a2eCards, dropdowns, modals, header
--q-border-color#e7e9f2#232b47All borders and dividers
Re-brand in one place Edit :root in assets/css/style.css. The dark theme reads from [data-bs-theme="dark"] in the same file.

Gradients

Two brand gradients ship with the template. Both are used sparingly — for the logo mark, the welcome banner and avatar fills.

Primary → accent

Buttons, logo mark, hero glow

Soft primary → soft accent
