2. DESCRIPTION (paste into the ThemeForest description box)
--------------------------------------------------------------------------------

  HTML description (recommended for the marketplace editor)

  <h3>Qevora AI SaaS UI — a complete Bootstrap 5 admin dashboard for AI and SaaS products</h3>

  <p>Qevora is a hand-built, framework-free HTML template: 83 responsive pages,
  a full AI workspace, CRM, projects, billing, team and reporting modules, and a
  component library where every example ships with Preview / HTML / CSS / JS
  panes and a copy button. Open <code>index.html</code> and it runs — no npm, no
  build step, no internet connection.</p>

  <h4>What makes it useful</h4>
  <ul>
    <li><strong>83 pages</strong> — dashboard and analytics, an AI workspace (chat,
      content generator, image generator, usage, history), 31 application pages,
      31 UI-kit pages, 6 authentication pages, 4 utility pages and the docs.</li>
    <li><strong>Light &amp; dark mode</strong> with a saved preference that follows the
      operating system; the dark palette re-tunes the brand colour instead of
      inverting it.</li>
    <li><strong>RTL ready</strong> — one switch in the header flips the layout and loads
      Bootstrap's RTL build; logical CSS properties handle the rest.</li>
    <li><strong>Responsive to 375 px</strong> — off-canvas navigation, stacked KPI cards
      and horizontally scrollable tables.</li>
    <li><strong>15+ Chart.js charts</strong> that re-read the theme tokens, so recolouring
      the palette recolours the charts.</li>
    <li><strong>Working demo interactions</strong> — create/edit dialogs, delete with
      undo, live search, filters, pagination, CSV import and export, file
      pickers, toasts and confirmations. All of it driven by data attributes and
      documented, so wiring a real API means replacing the handlers, not the
      markup.</li>
    <li><strong>Everything vendored</strong> — Bootstrap 5.3.3, Bootstrap Icons,
      Chart.js and the Inter font ship inside the package. No CDN, no tracking.</li>
    <li><strong>Documentation</strong> — a getting-started guide and a design-system
      reference, both inside the package.</li>
  </ul>

  <h4>Pages at a glance</h4>
  <p>Dashboard · Analytics · CRM dashboard · Leads · Customers · Customer details ·
  Pipeline · Projects · Project details · Kanban · Tasks · Calendar · Team chat ·
  Notifications · Products · Product details · Orders · Order details · Invoices ·
  Invoice details · Payments · Transactions · Subscriptions · Team · Roles ·
  Activity · Reports · Profile · Settings · Pricing · FAQ · Help ·
  AI overview · AI chat · Content generator · Image generator · AI usage ·
  AI history · 31 UI-kit pages · 6 auth pages · 404 / 500 / maintenance /
  coming soon · documentation.</p>

  <h4>Built for developers</h4>
  <ul>
    <li>Clean, commented HTML with semantic landmarks and accessible names.</li>
    <li>Every visual decision is a CSS variable in one file.</li>
    <li>Charts, tables, forms, modals, dropdowns, tabs, accordions, tooltips and
      toasts follow one design system, documented page by page.</li>
    <li>No jQuery, no framework lock-in, no compile step.</li>
  </ul>

  <p>Support and updates are handled through the item's support tab.</p>

9. IMAGE AND LICENSE AUDIT
--------------------------------------------------------------------------------

  Bundled libraries (all MIT or OFL, all allow redistribution inside a template)
    Bootstrap 5.3.3              MIT   assets/css/bootstrap*.min.css, assets/js/bootstrap.bundle.min.js
    Bootstrap Icons 1.11.3       MIT   assets/icons/bootstrap-icons/*
    Chart.js 4.4.3               MIT   assets/js/chart.umd.js
    Inter 5.0.18                 OFL   assets/fonts/inter/files/*.woff2 + LICENSE.txt

  Images
    Every image in the package is an SVG or a CSS placeholder created for this
    template (logo, favicon, product placeholders, social cover). No third-party
    photography, no stock icons and no bundled screenshots, so there is nothing
    to credit beyond the libraries above.

  Marketplace imagery
    The cover and preview images are generated from the template's own design
    tokens and demo data by marketplace/build-images.mjs — they contain no
    third-party content. They are drawn with the Inter font that ships with the
    package (SIL OFL 1.1), so they may be used on the item page.

  Names and data
    All company names, people, avatars (initials only), amounts and metrics are
    fictional. E-mail addresses use example.com, the domain reserved by RFC 2606
    for documentation and examples.
