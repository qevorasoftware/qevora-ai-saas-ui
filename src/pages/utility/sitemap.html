About this list

  • The list above is generated from the same page inventory the build reads, so it cannot go stale: every file in src/pages.mjs appears exactly once, and every link resolves to a page that ships.
  • 404.html at the project root is not a separate page. It is a copy of utility/404.html with root-relative asset paths, written for hosting platforms that serve a site-root fallback document.
  • Development-only folders — src/, tools/ and marketplace/ — are not part of the buyer package and are intentionally absent from this list.
  • Every page is reachable from the sidebar or from the documentation, and the terms and privacy pages are linked from the footer of every page as well.
