Design system

One token layer drives the whole template. Change a value here in assets/css/style.css and every page, chart, badge and dark-mode surface follows automatically.

Documentation Colour page
Tokens are declared as CSS custom properties on :root and re-declared under [data-bs-theme="dark"]. Bootstrap's own --bs-* variables are bridged to them, so Bootstrap components inherit the palette without overrides.

Dark mode

  • Dark mode is an attribute, not a separate stylesheet: <html data-bs-theme="dark">.
  • Colour tokens are re-declared under that selector with higher-contrast values — the brand indigo moves from #4f46e5 to a lighter tint so it stays readable on dark surfaces.
  • assets/css/dark.css only holds component-level polish: input backgrounds, image dimming, sidebar hairlines and modal edges.
  • Charts and progress rings listen for the qevora:themechange event and redraw with the new palette.
  • The choice is stored in localStorage under qevora-theme; system follows the operating system setting.

RTL rules

  • Set dir="rtl" on <html>; the sidebar script also swaps bootstrap.min.css for bootstrap.rtl.min.css at runtime.
  • Layout uses logical properties (padding-inline-start, inset-inline-end), so the shell mirrors without extra CSS.
  • assets/css/rtl.css corrects the few cases that cannot be logical — icon rotations, timeline rails, progress origin and chart legends.
  • Charts keep left-to-right data order, which is correct for time series in every locale.
  • Test any new component at dir="rtl" before shipping it — the header has a toggle for exactly this.

Do & don't

Do

  • Change tokens first — a colour asked for twice is a token that is missing.
  • Reuse .card, .btn-soft-* and .badge-soft-* instead of inventing new surfaces.
  • Keep one primary action per screen and one accent colour per chart.
  • Check every new block in light, dark, RTL and at 375 px width.
  • Write the label first, then attach the icon — never the other way round.

Don't

  • Hard-code hex values in page markup — use the token or a Bootstrap text/bg utility.
  • Add a second font family or a heavier weight than 700.
  • Stack more than two shadow levels in one view.
  • Use colour alone to communicate state — always pair it with text or an icon.
  • Override Bootstrap variables inline; extend the token block instead.
