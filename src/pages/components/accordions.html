Usage notes

  • The toggle button always needs aria-expanded and aria-controls — the demo markup includes both.
  • Use data-bs-parent for FAQ lists, and leave it out for wizard-style forms where users compare panels.
  • Never nest an accordion inside another accordion panel; use a card with a header instead.
  • Headings use real <h3>/<h4> elements so the page outline stays valid for screen readers.
  • Keep panel bodies short — if a panel needs more than three paragraphs, it belongs on its own page.
