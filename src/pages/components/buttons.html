Buttons

Bootstrap's button system plus Qevora's soft, ghost and gradient variations. Every button in the template comes from this page — nothing is styled per screen.

Docs

Solid buttons

The default action style. Use one primary button per view to keep the main action obvious.

<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-info">Info</button>
<button class="btn btn-dark">Dark</button>
<button class="btn btn-white">White</button>
<button class="btn btn-primary" disabled>Disabled</button>

<!-- Qevora gradient button -->
<button class="btn btn-gradient"><i class="bi bi-stars"></i> Gradient</button>

Soft and outline variants

Soft buttons are used for secondary actions inside cards and table toolbars — they stay quiet next to a solid primary button.

<button class="btn btn-soft-primary">Soft primary</button>
<button class="btn btn-soft-success">Soft success</button>
<button class="btn btn-soft-warning">Soft warning</button>
<button class="btn btn-soft-danger">Soft danger</button>
<button class="btn btn-soft-info">Soft info</button>
<button class="btn btn-soft-secondary">Soft neutral</button>
<button class="btn btn-ghost">Ghost</button>

<button class="btn btn-outline-primary">Outline primary</button>

Sizes and icons

Icon-only buttons always need an aria-label so screen readers can announce them.

<button class="btn btn-primary btn-sm">Small</button>
<button class="btn btn-primary">Default</button>
<button class="btn btn-primary btn-lg">Large</button>

<button class="btn btn-primary"><i class="bi bi-plus-lg"></i> New project</button>
<button class="btn btn-primary">Continue <i class="bi bi-arrow-right"></i></button>

<button class="btn btn-icon btn-primary" aria-label="Add item">
  <i class="bi bi-plus-lg"></i>
</button>

Buttons with state

Loading, toggled and grouped buttons. Toggle buttons use aria-pressed.

<!-- Loading state -->
<button class="btn btn-primary" disabled>
  <span class="spinner-border spinner-border-sm" aria-hidden="true"></span>
  <span role="status">Saving…</span>
</button>

<!-- Button group -->
<div class="btn-group" role="group" aria-label="View mode">
  <button class="btn btn-white active">Day</button>
  <button class="btn btn-white">Week</button>
  <button class="btn btn-white">Month</button>
</div>

<!-- Toggle button -->
<button class="btn btn-soft-primary" aria-pressed="true">
  <i class="bi bi-bookmark-check"></i> Following
</button>

Usage notes

  • Use .btn-primary once per view for the main action; everything else should be soft, ghost or white.
  • Prefer .btn-icon with an aria-label instead of text-only icon links in tables.
  • .btn-soft-* uses the matching soft background token, so it adapts to dark mode automatically.
  • Buttons inherit the 8px radius from --q-radius-sm; change the token to restyle every button at once.
