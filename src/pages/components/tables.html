Usage notes

  • Always wrap tables in .table-responsive — it is what keeps the layout intact on tablets.
  • Search inputs use data-table-filter="#tableId"; the empty state must use data-table-empty inside the same card.
  • Sortable headers only need data-sort="text|number" — the script adds .table-sort and the caret.
  • Selection: a master checkbox with data-select-all="#tableId" controls every data-row-select box in the body.
  • Pagination lives in .table-footer with data-paginate, data-per-page and data-page buttons (values prev, next or a number).
  • Right-align money columns and use tabular numbers so digits line up between rows.
