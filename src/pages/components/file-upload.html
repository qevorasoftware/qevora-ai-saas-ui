Usage notes

  • The demo zone only lists chosen files — connect the change event to your own endpoint for a real upload.
  • Always name the accepted formats and the size limit in the zone description; users should not discover limits from an error.
  • Set the accept attribute on the hidden input, but validate the file type on the server as well.
  • Keep destructive actions (delete) as ghost icon buttons with an explicit aria-label naming the file.
  • The drop zone adds .is-dragover while a file hovers over it, and removes it on drop and drag-leave.
