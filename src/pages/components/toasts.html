Usage notes

  • Programmatic toasts: Qevora.toast("Saved", "success", "Customers") — title is optional.
  • Variants map to Bootstrap colours: primary, success, warning, danger, info.
  • Toasts auto-dismiss after 3.2 seconds and stack upwards from the bottom-right corner.
  • Use a toast for confirmation of an action the user just took — never for validation errors, which belong next to the field.
  • Keep the message under 90 characters; put the record name first so it is readable at a glance.
