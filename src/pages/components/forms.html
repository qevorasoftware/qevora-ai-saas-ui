Usage notes

  • Every input needs a <label> tied to it by for/id. Placeholders are examples, never labels.
  • Use .form-control-sm inside table toolbars and .form-control-lg for single-field pages such as auth screens.
  • Keep helper text in .form-text and error text in .invalid-feedback — do not mix them.
  • Validate on submit (and on blur for long forms), never on every keystroke.
  • Group related fields in .row g-3 so form spacing stays identical on every page.
