Icons

Bootstrap Icons 1.11.3 is bundled locally as a web font, so icons work offline and never trigger a third-party request.

Full icon set

How to use an icon

Add the class name to an <i> element

<i class="bi bi-stars"></i>

<!-- Inside a button -->
<button class="btn btn-primary"><i class="bi bi-plus-lg"></i> New project</button>

<!-- Decorative icons should be hidden from screen readers -->
<i class="bi bi-bell" aria-hidden="true"></i>

<!-- Meaningful icons need a label -->
<i class="bi bi-check-circle-fill" role="img" aria-label="Completed"></i>
