Spacing

A six-step spacing scale keeps dashboard density consistent. Bootstrap's spacing utilities map directly onto it.

Spacing tokens

Defined in style.css as --q-space-*

Token Value Bootstrap utility Typical use
--q-space-xs4px.gap-1Icon to label inside buttons and badges
--q-space-sm8px.gap-2Between inline controls
--q-space-md16px.gap-3Grid gutters, card padding on mobile
--q-space-lg24px.gap-4Space between dashboard sections
--q-space-xl32px.p-4Card padding on desktop
--q-space-xxl48px.py-5Marketing-style page sections

Visual scale

Each bar represents one step of the scale at real size.

xs · 4px
sm · 8px
md · 16px
lg · 24px
xl · 32px
xxl · 48px 
:root {
  --q-space-xs: 4px;
  --q-space-sm: 8px;
  --q-space-md: 16px;
  --q-space-lg: 24px;
  --q-space-xl: 32px;
  --q-space-xxl: 48px;
}

/* Use them in your own rules */
.my-panel {
  padding: var(--q-space-lg);
  margin-bottom: var(--q-space-xl);
}
