Avatars

Initials, gradient fills, status indicators and stacked groups. No avatar photography is bundled, so there are no image-licensing questions for buyers.

Sizes

Six sizes from xs to xxl. The default size is md (40px).

Gradient fills

Eight gradient classes ship with the template: .bg-avatar-1 through .bg-avatar-8. They are deterministic, so the same person always gets the same colour if you map the class in your own data layer.
