Body text and helpers

Base body size is 0.9375rem (15px) with a 1.6 line height. Use the small helpers for metadata and table captions.

Lead paragraph — 1.25rem, used for section introductions on marketing-style pages.

Body copy at 0.9375rem. This is the default size for paragraphs, table cells and form labels across the dashboard, CRM, finance and AI pages.

Small text (fs-7, 0.8125rem) for card subtitles and helper copy.

Meta text (fs-8, 0.75rem) for timestamps and table metadata.

Captions (fs-9, 0.6875rem) for the smallest annotations.

Links use the primary token — this is a link — and inherit hover states from Bootstrap.

Inline code looks like --q-primary and keyboard keys look like ⌘ K.

Block quotes are used for documentation notes and customer testimonials.

Weight scale

Four weights are bundled — nothing else is downloaded

Inter Regular — 400 Body copy, table cells, form values
Inter Medium — 500 Buttons, navigation labels, table headers
Inter SemiBold — 600 Headings, badges, emphasis
Inter Bold — 700 KPI values, page titles, large numbers
