Usage notes

  • Native inputs always submit YYYY-MM-DD and HH:MM values — store those formats and format for display in your own layer.
  • Use min/max to block impossible dates, but still validate on the server.
  • Show the timezone next to any time the user schedules, or store UTC and display the workspace timezone.
  • Add quick range buttons above a range picker — nine out of ten users pick a preset rather than a custom range.
  • Date inputs are never empty-styled: always set a sensible default so the field does not render blank in demos.
