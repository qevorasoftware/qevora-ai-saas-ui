Usage notes

  • Pair every data-bs-target with a matching .tab-pane id — the template never uses JavaScript tab logic.
  • Keep tab labels to one or two words; move filters and ranges into a toolbar above the tabs.
  • Underline tabs belong to page sections, pills belong to a card or a toolbar, vertical tabs belong to settings.
  • Add a count badge inside a label when the tab reveals a list — it saves users a click.
  • Panels animate with Bootstrap's fade class; respect reduced-motion users by leaving the default fade as-is (it is short).
