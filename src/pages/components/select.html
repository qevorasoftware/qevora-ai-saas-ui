Usage notes

  • Prefer native selects — they render the operating system's own picker on mobile, which users already trust.
  • Keep the first option meaningful ("All statuses"), never an empty placeholder, when the select is a filter.
  • Add size="4" (or more) to a multi-select so the selected rows are visible without scrolling.
  • Search inputs should debounce at about 250 ms when they filter a table through JavaScript.
  • Removable chips need a descriptive aria-label on the close button — "Remove" alone is not enough.
